# Contributing to SubSync CLI Toolkit

Thank you for your interest in contributing to SubSync CLI Toolkit! We welcome contributions from developers of all skill levels.

## How to Contribute

1. Fork the Repository: Create your own fork of the project.
2. Create a Feature Branch:
   git checkout -b feature/your-feature-name
3. Commit Your Changes: Follow standard conventional commit formats (feat:, fix:, docs:, test:).
4. Run Unit Tests: Ensure all tests pass prior to submitting code:
   python -m unittest discover tests
5. Open a Pull Request: Describe the proposed changes clearly along with any relevant context or issue references.

## Code of Conduct

Please maintain a respectful, inclusive, and professional environment across all issues and pull requests.
